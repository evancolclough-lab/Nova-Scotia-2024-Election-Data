Dashboard Documentation

This page explains the full Nova Scotia poll-by-poll app, including the main dashboard, the separate constituency comparison page, the multi-poll analysis page, the interactive map page, the dual-election data flow, and how the displayed numbers are calculated.

What was built

  • A static HTML dashboard that runs entirely in the browser with no backend.
  • A top-level election toggle with fully separate 2024 and 2021 modes, with 2024 as the default view.
  • A main dashboard page for filtering, charting, and browsing poll-level results.
  • A separate constituency comparison page so head-to-head riding comparisons are not mixed into the main dashboard workflow.
  • A separate multi-poll analysis page for selecting up to 10 polls across one or more districts.
  • A separate interactive map page built from polling-division polygons so you can click into district and poll information geographically.
  • A documentation page that explains the features, data structure, and calculations.
  • Build scripts that convert both the Excel workbooks and the polygon KMZ into static JSON files for the app.

Main Dashboard Features

  • An election toggle at the top of the page lets you switch between the 2024 and 2021 provincial elections.
  • Switching elections reloads the dashboard from the selected election dataset instead of mixing years together.
  • Constituency filter for narrowing the dashboard to one district or viewing all districts together.
  • Poll type filter for switching between regular polls, mobile polls, combined polls, central polls, returning office polls, and out-of-district entries.
  • Free-text search that matches district names, poll codes, poll types, locations, and winning candidates.
  • Summary cards showing districts in scope, polls in scope, total votes, and weighted turnout for the current filtered view.
  • A district spotlight that changes when a constituency is selected.
  • A vote totals chart for the current filtered view.
  • A turnout chart that switches between poll-level and district-level comparisons depending on the current filter state.
  • The province-wide turnout chart now shows all constituencies in turnout order, not only a shortened top list.
  • A collapsible section titled Full province wide list of polls.
  • The poll table starts collapsed by default and can be expanded on demand.
  • The poll table is district-first: each district expands to reveal its polls instead of showing one long province-wide flat list.
  • In 2024, grouped vote charts use party totals. In 2021, grouped vote charts use candidate names only.

District Spotlight Features

  • Winning candidate summary for the currently selected district or filtered district view.
  • Turnout, ballots cast, and poll count for the current district scope.
  • Vote share bars for all candidates in the selected district view.
  • Best poll and worst poll by turnout percentage.
  • Best and worst poll callouts include the poll code, turnout percentage, and polling location.

The best/worst poll feature is intentionally limited to valid Regular Poll rows with turnout between 0% and 100%. This excludes special rows such as mobile polls or combined entries that can produce misleading percentages.

Comparison Page Features

  • A dedicated Compare Constituencies button on the main dashboard opens a separate comparison page.
  • The comparison page has the same election toggle, so 2024 and 2021 comparisons stay separate there as well.
  • Two constituency selectors let you compare any pair of ridings side by side.
  • Each side shows winner, turnout, votes cast, electors, and number of polls.
  • A center summary shows turnout gap, vote gap, and which district has the higher total vote count.
  • A grouped bar chart compares vote totals across the two constituencies.
  • A vote share breakdown compares each party or candidate grouping on the left and right side of the page.

Multi-Poll Analysis Features

  • A dedicated Multi-Poll Analysis page is linked from both the main dashboard and the comparison page.
  • The page follows the same election-year toggle pattern as the rest of the app, so 2024 and 2021 remain separate.
  • The workflow is step-based: first choose districts, then choose up to 10 polls, then open the analysis results.
  • The district picker uses a compact multi-column grid, and the poll picker groups available polls under collapsible district headers.
  • Selected districts and selected polls appear in summary chips above the step controls.
  • The results section shows summary cards, turnout coverage, best and worst selected polls, district leader margins, and a comparison table for the selected polls.
  • Empty states are shown when no districts are selected, when no polls are selected, or when searches return no matches.
  • The page includes navigation back into poll selection after results are displayed.

Map Page Features

  • A dedicated Map Explorer page is linked from the dashboard, comparison page, and multi-poll page.
  • The map page uses the same election-year toggle, so 2024 and 2021 map details stay separate.
  • The page loads the March 2026 polling-division polygons and displays them as clickable shapes on a Leaflet map.
  • In 2024, polygons are coloured by the winning party for the matched poll: PC Party in blue, NDP in orange, and Liberal in red.
  • In 2024, the winning-party colour also varies in shade: lighter fills indicate a weaker winning vote share, and darker fills indicate a stronger winning vote share in that poll.
  • In 2024, Other winner polls use a grey fill, while polygons with no exact poll match are left clear with only their outline visible.
  • In 2021, polygons are shaded by turnout bands instead of winning-party colours.
  • District and text filters let you narrow the map to one district or search by poll code, location, service area, or winner.
  • Map filters are distinct by election year, so a district or search view in 2024 does not overwrite the map view you left in 2021.
  • Clicking a polygon opens a details panel showing the selected polling division, turnout, leader, location, and candidate totals when they are available.
  • The details panel also includes district-wide context for the selected polygon, including district winner, turnout, votes cast, and poll count.
  • If a polygon has no exact election-row match, the page still shows the boundary metadata and district summary when possible instead of failing silently.
  • The map includes summary cards for polygons in view, districts in view, exact poll matches, and boundary-only records.
  • The map panel includes a full-screen button so the Leaflet view can expand for closer geographic inspection.

Navigation and Layout

  • The main dashboard hero includes buttons for Documentation, Compare Constituencies, Multi-Poll Analysis, and Map Explorer.
  • The comparison page includes buttons for returning to the dashboard, opening the documentation page, opening the multi-poll page, and opening the map page.
  • The multi-poll page includes buttons back to the dashboard, compare page, documentation page, and map page.
  • The documentation page links back to the main dashboard, the compare page, the multi-poll page, and the map page.
  • The dashboard, compare page, multi-poll page, and map page all include an election-year toggle near the top of the hero area.
  • The app is mobile-friendly and includes responsive layout changes for cards, controls, charts, and the poll table.
  • On smaller screens, the poll table becomes stacked cards with labels so the data remains readable without horizontal scrolling.
  • The map page also collapses to a one-column layout on smaller screens so the map and details panel remain usable on mobile.
  • The page background is fixed to the viewport so expanding the poll table does not change the overall page colour.

Theme and Dark Mode

  • The main dashboard automatically follows the device theme using prefers-color-scheme.
  • The separate compare page also follows the device theme automatically.
  • The map page switches both its page styling and base map tiles to match light or dark mode.
  • Charts update their axis labels, legends, and grid colors to match light or dark mode.
  • If the device theme changes while the page is already open, the charts rerender to stay readable.
  • This documentation page also supports the device dark mode.

Data Source and Processing

The app now uses two source workbooks:

  • 42PGE_PollbyPoll_AllEDs_TurnOut_FINAL.xlsx for the 2024 election.
  • 41PGE_PollbyPoll_AllEDs_TurnOut_FINAL.xlsx for the 2021 election.

Each worksheet represents one electoral district. The build script reads the workbooks directly from the Excel XML structure, extracts poll rows, ignores summary/footer rows, and then writes a single JSON file with separate 2024 and 2021 sections under a shared top-level metadata block.

The map page also uses a polygon source file:

  • ProvincialPollingDivisionPolygons_March_2026.kmz for the polling-division map geometry.

For each poll row, the script stores the district, poll code, poll type, polling location, elector count, total votes, rejected ballots, declined ballots, and each candidate's votes. It also creates district summaries and election-specific metadata for both years.

The map build script reads the KMZ file, extracts each polygon placemark, parses the embedded district and poll metadata, simplifies the geometry, and writes a browser-ready static map JSON file.

The 2021 mode is intentionally grouped by candidate name only. It does not attempt to normalize party groupings across the 2021 workbook in the charts and grouped summaries.

Key calculations

Poll turnout = total votes / electors

Each poll's turnout is calculated only when the workbook includes an elector count for that poll.

Valid votes = sum of all candidate votes in that poll or district

Rejected ballots and declined ballots are not included in valid votes.

Candidate vote share = candidate votes / valid votes

Vote share is computed for both poll-level candidate results and district-level candidate totals.

Grouped vote totals = sum of votes for each grouping in the active election mode

In 2024, the grouping is by party. In 2021, the grouping is by candidate name.

Weighted turnout = sum of total votes in scope / sum of electors in scope

This is the figure shown in the dashboard summary cards. It is weighted because it uses raw totals rather than averaging turnout percentages equally across polls.

Leading candidate = candidate with the highest vote total in the current row or filtered view

In the poll table, the leading candidate is the highest vote getter for that poll. In the district spotlight, the leading candidate reflects the currently filtered district view.

Best poll / worst poll = regular poll with the highest / lowest valid turnout percentage in the selected district view

These spotlight callouts use only valid regular poll rows so special or aggregate rows do not distort the result.

Multi-poll weighted turnout = sum of total votes across selected polls / sum of electors across selected polls

The multi-poll page uses the same weighted-turnout approach as the main dashboard, but it applies it only to the user-selected polls.

Multi-poll best / worst poll = selected poll with the highest / lowest turnout percentage

On the multi-poll page, the best and worst poll callouts are chosen from the currently selected poll set rather than from an entire district.

District margin in multi-poll analysis = total votes for the leading candidate across selected polls in a district - total votes for the runner-up across those same selected polls

The margin shown on the multi-poll page is not a full-district election margin unless all polls from that district are selected. It is the margin within the subset of selected polls for that district.

Multi-poll candidate totals = sum of each candidate's votes across the selected polls in the current district or row

The comparison table shows each selected poll's candidate totals directly, and the district margin cards aggregate those totals across all selected polls in each district.

Map poll join = exact match on district number + poll code between the polygon metadata and the selected election dataset

The map page joins each polygon to election results by matching the polygon district number and poll code to the selected election's poll rows. If there is no exact match, the polygon still appears, but it is treated as boundary-only context rather than a fully matched election poll.

2024 map fill = winning party color for the matched poll, with shade intensity based on the winning vote share

In 2024, a matched polygon is filled by the winning party for that poll: PC Party is blue, NDP is orange, and Liberal is red. Other matched winners use a grey fallback color, and polygons without an exact match are left clear. Within those party colours, lighter fills represent smaller winning vote shares and darker fills represent stronger winning vote shares for that poll.

2024 map shade strength = winning candidate votes / valid votes in that poll

The 2024 intensity gradient uses the leading candidate's vote share in the matched poll. The party colour stays the same, but the fill darkens as the winning share increases.

2021 map fill = turnout band based on the matched poll's turnout percentage

In 2021, a matched polygon is filled from turnout bands based on that poll's turnout percentage. Polygons without an exact match are shown in a neutral fallback color.

Poll type rules

The importer assigns poll types from the poll code text:

  • Mobile if the code contains "Mobile"
  • Out-of-District if the code contains "Out-of-District"
  • Returning Office if the code starts with RO-
  • Central Poll if the code starts with CP
  • Combined Poll if the code contains /
  • Regular Poll otherwise

Important caveat

Some workbook rows contain votes but no elector count. In those cases, the dashboard can still display vote totals, but turnout cannot be computed for that row. The weighted turnout card currently sums all votes in the filtered scope and divides by the summed electors that are available.

That means filtered views containing many rows without elector counts may slightly overstate turnout. If you want, this can be changed so turnout uses only rows that have both votes and elector counts.

The separate best/worst poll spotlight already avoids this issue by excluding rows with missing electors, missing votes, invalid percentages, and non-regular poll types.

The map page has a different caveat: the polygon file is from March 2026, while the election data is from 2024 and 2021. Most polygons join cleanly by district number and poll code, but some polygons are boundary-only because there is no exact historical poll row to match.

Files in the App

  • index.html: main dashboard structure, navigation buttons, and the election toggle container.
  • app.js: main dashboard filtering, election switching, spotlight logic, charts, collapsible poll table behavior, and theme-aware chart rendering.
  • compare.html: standalone constituency comparison page with its own election toggle.
  • compare.js: comparison page election switching, selectors, summaries, and theme-aware comparison chart logic.
  • multi-poll.html: step-based multi-poll selection and analysis page.
  • multi-poll.js: district selection, poll selection, step flow, turnout summaries, margin calculations, and selected-poll comparison table logic.
  • map.html: standalone map page structure, map filters, stats, and details panel.
  • map.js: Leaflet map setup, election-aware polygon joins, filters, detail rendering, and dark-mode base map switching.
  • documentation.html: this feature and calculation reference page, including dark mode support.
  • styles.css: shared styling, responsive behavior, and automatic dark mode across the app.
  • data/nova-scotia-poll-results.json: generated multi-election dataset used by the app.
  • data/nova-scotia-poll-map.json: generated polling-division geometry and metadata used by the map page.
  • scripts/build_dataset.py: workbook parser and JSON generator for the combined 2024 + 2021 data file.
  • scripts/build_map_data.py: KMZ parser and static map-data generator for the polling-division page.
